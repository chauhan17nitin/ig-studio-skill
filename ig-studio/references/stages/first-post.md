# Stage: first post

Make one complete post from the user's first-choice format, using the "Create one post" steps in `weekly-run.md`. Someone is present, so ask rather than guess.

Show them the file and caption, then ask what's off. Save each correction to the format file or `rules.md`, so it shapes later posts. Revise and re-render until they're happy.

Agree an upload date with them and file the post under it, with status `ready` in `log.md`. A later weekly run counts it as one of that week's slots. Set `stage: weekly-setup`.
