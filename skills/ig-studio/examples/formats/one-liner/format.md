# Format: One-liner

Example only, not a default. It shows what a complete format file looks like.

| Field | Value |
|---|---|
| Name and job | One-liner. Reach new people with a single relatable line. |
| Container | Reel |
| Structure | Plain background, first line, second line lands under it, end card |
| Copy rules | Two short lines, under 20 words in total. The second line carries the payoff. No voiceover. |
| Production | Rendered |
| Assets | End card image, with a text fallback. Sound is optional, and trending audio can be added in the app. |
| Cadence | Flexible |
| Reel length limit | 20s |
| Success test | Median views above the account's previous median across 5 posts, with at least 1 share, save, comment or follow |
| Status | Testing, since the first post |

## Notes

- Specific, everyday references work better than general statements.
- Each post's `config.json` holds the lines, and `template.html` draws them.
- This example belongs to a fictional bakery. Replace all of it for a real brand.
- The sample post deliberately names missing assets, to show the text end card and silent-track fallbacks. Real posts live in `posts/<format>/`.
